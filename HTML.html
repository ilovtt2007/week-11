HTML 태그 요약 및 정리 가이드

HTML 주요 태그들을 기능별로 분류한 요약표입니다.

1. 문서 기본 및 메타정보 태그

태그

디스플레이 유형

설명

<!DOCTYPE html>

-

HTML5 표준 문서임을 정의하는 선언문

<html>

-

HTML 문서의 최상위(Root) 요소

<head>

-

메타데이터, 제목, 스타일시트 링크 등을 담는 머리말 영역

<title>

-

브라우저 탭 또는 검색 결과에 표시되는 웹 페이지 제목

<body>

-

웹 브라우저 화면에 실제 출력되는 모든 콘텐츠 영역

<meta>

-

문자 인코딩(UTF-8), 뷰포트 설정, 검색엔진 키워드 등 메타정보 정의

<link>

-

외부 CSS 스타일시트, 파비콘 등의 자원을 연결

<style>

-

문서 내부에 직접 CSS 스타일을 작성

<script>

-

자바스크립트 코드를 실행하거나 외부 스크립트 파일 연결

2. 시맨틱 레이아웃 태그 (구조화)

태그

디스플레이 유형

설명

<header>

Block

페이지나 섹션의 상단 헤더 영역 (로고, 검색바 등)

<nav>

Block

내비게이션 메뉴 및 대분류 링크 모음 영역

<main>

Block

문서의 핵심적이고 독자적인 주요 콘텐츠 영역 (페이지당 1개 권장)

<section>

Block

주제별로 콘텐츠를 나누는 독립적인 구획 영역

<article>

Block

독립적으로 배포 및 재사용 가능한 콘텐츠 (블로그 글, 뉴스 기사 등)

<aside>

Block

본문과 간접적으로 연관된 사이드바, 광고, 관련 링크 영역

<footer>

Block

페이지나 섹션의 하단 푸터 영역 (저작권, 연락처, 이용약관 등)

<div>

Block

의미 없는 범용 블록 레이아웃 컨테이너

<span>

Inline

의미 없는 범용 인라인 컨테이너 (텍스트 일부분 스타일 지정용)

3. 텍스트 및 서식 태그

태그

디스플레이 유형

설명

<h1> ~ <h6>

Block

문서의 제목/주제 (1이 가장 크고 6이 가장 작음)

<p>

Block

하나의 단락(Paragraph) 정의

<br>

Inline

강제 줄 바꿈 (단일 태그)

<hr>

Block

단락 간 구분을 위한 수평 분리선 (단일 태그)

<strong>

Inline

중요한 텍스트 강조 (시각적 굵은 글씨 및 의미적 강조)

<b>

Inline

단순 시각적 굵은 글씨 (의미적 강조 없음)

<em>

Inline

강조 텍스트 (기울임꼴 및 의미적 강조)

<i>

Inline

단순 시각적 기울임꼴 (의미적 강조 없음)

<mark>

Inline

하이라이트(형광펜) 효과 지정

<small>

Inline

주석, 덧붙이는 글, 저작권 표시 등 작게 표시할 텍스트

<code>

Inline

컴퓨터 코드 조각을 고정폭 폰트로 표시

<pre>

Block

서식이 지정된 텍스트 (공백과 줄 바꿈을 작성한 그대로 유지)

<blockquote>

Block

외부 출처로부터의 긴 인용구 문단

4. 링크 및 미디어 태그

태그

디스플레이 유형

설명

<a>

Inline

하이퍼링크 생성 (href 속성으로 이동할 URL 지정)

<img>

Inline

이미지 삽입 (src 경로, alt 대체 텍스트 필수)

<audio>

Inline

오디오 재생 파일 삽입 (controls, autoplay 등 사용)

<video>

Inline

비디오 재생 파일 삽입 (controls, width, height 등 사용)

<source>

-

<audio>나 <video> 내부에서 미디어 파일의 경로와 형식 지정

<iframe>

Inline

현재 페이지 내에 다른 웹 페이지나 외부 콘텐츠(유튜브 등) 내장

5. 목록(List) 및 표(Table) 태그

태그

디스플레이 유형

설명

<ul>

Block

순서가 없는 목록 생성 (기본 점 기호)

<ol>

Block

순서가 있는 목록 생성 (기본 숫자 기호)

<li>

Block

목록 내부의 각 항목(List Item)

<table>

Block

표(Table) 데이터 전체를 감싸는 태그

<tr>

Block

표의 행(Table Row) 정의

<th>

Block/Inline

표의 제목 셀(Header Cell, 자동 굵게 및 중앙 정렬)

<td>

Block/Inline

표의 일반 데이터 셀(Data Cell)

<thead>

Block

표의 상단 헤더 영역 그룹화

<tbody>

Block

표의 본문 데이터 영역 그룹화

<tfoot>

Block

표의 하단 합계/요약 영역 그룹화

6. 폼(Form) 및 입력 태그

태그

디스플레이 유형

설명

<form>

Block

사용자 입력을 서버로 전송하기 위한 양식 전체 영역

<input>

Inline

다양한 유형의 입력 필드 생성 (type="text", password, checkbox, radio, file 등)

<label>

Inline

입력 요소(input)에 이름표를 붙여 접근성 및 클릭 영역 확장

<textarea>

Inline

여러 줄의 텍스트를 입력받는 영역

<button>

Inline

클릭 가능한 버튼 생성

<select>

Inline

드롭다운 선택 메뉴 상자 생성

<option>

-

<select> 드롭다운 메뉴 안의 세부 선택 항목

<fieldset>

Block

폼 내부의 관련 요소들을 박스로 그룹화

<legend>

Block

<fieldset> 그룹에 제목을 붙임
